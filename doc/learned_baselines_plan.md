# 학습 기반 방법 비교 (2026-10-09 지시)

주장: "우리 학습 방법이 다른 학습 기반 방식보다 빠르고, 표현을 더 잘하고, 더 잘 일반화한다."

결정 (사용자):
- 베이스라인: 3DGSim, NGFF. **GausSim 은 제외** (학습 코드 미공개)
- 우리: 하던 대로 **증분 포텐셜로 학습** (simplex GNN)
- 재질: 베이스라인들이 다루는 재질 전부
- 정답 시뮬레이터: 천 = MPMAvatar, 파괴 = GaussianFluent, 그 밖 = PG
- 같은 장면·같은 궤적으로 모든 방법을 학습·평가. 베이스라인은 공식 학습 설정 그대로 (공식에 없는 부분은 묻는다)

지표: 성능(학습 시간·메모리·추론 FPS 단독 GPU) / 물리(CD·EMD 같은 인덱스·RMSE ÷ L, 보존량, det F, 긴 롤아웃 발산) / 시각(PSNR·SSIM·LPIPS·FID·FVD)
일반화: 새 초기 조건, 학습보다 긴 롤아웃, 처음 보는 형상, 물성 범위 밖

진행: 베이스라인 설치·공식 예제 재현 -> 재질 목록·데이터 형식 확인 -> 공통 데이터셋(형상 하나로 먼저) -> 학습 -> 평가
