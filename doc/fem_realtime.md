# FEM pcg 판 실시간화 (lego L000, 2026-10-27~)

사용자 지시 (10-27): "lego FEM 프로파일링부터 하고 속도 가속할 수 있는 거 다 가속하고(커스텀 커널 작성 포함) 돌려서 실행 성능 측정".
기준 = 커밋 15250d4 수렴판 (`exe/fem_roll.sh lego … full`, FEM_SOLVER=pcg, FEM_PCG_MAX=10000, FEM_EIG_FLOOR=1e-6, FEM_LM=1,
FEM_LM_MUMIN=0, FEM_EIG_PROJ=abs, tol 1e-2), 결과 `lbours/fem2_lego/run`: **L000 80 프레임 오차 11.304 %**.
한 출력 프레임 = 증분 포텐셜 풀이 한 번 (h = 1/60, fem.jsonl 프레임당 기록 하나 -- 서브스텝 없음).
오차 = 롤아웃 평균 위치 오차 / EXT (고정 상수, 기존과 같은 지표).

### B. (1) 축약 검증 -- 덤프 t=40 (프레임 40 상태, 기준 실행 조각에서 이어서; `lbours/fem_rt_lego/dump40`)
`exe/fem_fast_check.py` (float32 = 실행과 같은 정밀도, 기존 경로 값은 덤프의 파이프라인 값). 입자 313,750, 사면체 43,340.

| 항목 | 빠른 경로 vs 기존 파이프라인 |
|---|---|
| 증분 포텐셜 E | 상대차 2.2e-7 (float64 로 계산하면 5.8e-8 -- 남은 차는 기존 float32 합산 잡음) |
| 기울기 (자유 노드) | 상대차 1.07e-5 (float64 판도 1.04e-5 -- 기존 float32 경로의 잡음 수준) |
| 입자 12x12 (작은 함수, 이중 역전파 12 회) | 5.2e-6 |
| 사면체 축약 12x12 (매핑 항등 입자: 관성 일관질량 + Bᵀ(ΣV K)B, 바닥 후보: 입자 12x12) | 5.25e-6 |
| ∇λ 로 만든 B vs 파이프라인 ∂J/∂U (매핑 항등 입자) | 3.2e-6 |

- **사용자 제안 (사면체 안 F 상수) 은 정확한 축약이 아니다**: 입자 F^n 은 세계 고정 격자 위를 입자가 지나가며 쌓인 것이라 같은 사면체 안에서도
  입자마다 다르다. `exe/fem_reduce_check.py` (float64, t=40): 사면체 안 |F_p − F̄_T| 평균 0.062 최대 1.98 (|F−I| 평균 1.46 -- 회전 포함),
  탄성 에너지 Σ V_p ψ(J_T F_p) = 208.301 vs Σ_T V_T ψ(J_T F̄_T) = 157.269 (**24.5 % 차**, 바닥 후보 없는 사면체만 19.8 %), 탄성 헤시안 4.2 % 차
  -> 이 근사는 쓰지 않았다.
- 검증 수치 (같은 스크립트, float64): 후보 없는 사면체에서 B_p 사면체 안 최대 차 **0** (barycentric 이라 정확히 상수);
  입자 HL(기존 파이프라인) = 관성 m/h² λλᵀ⊗I + V Bᵀ K B 상대오차 1.1e-7 (σ_min≤0.01 입자 1 개 제외); A 공간 정확 축약 vs 입자별 12x12 합 **1.8e-16**;
  관성 직접 합 vs 일관 질량 ½UᵀMU − bᵀU + c **2.5e-12**. 정확한 축약은 **A=I+∇u 공간**에서 한다: ψ(A F_p) 의 A-헤시안 K_p (9x9) 를 입자마다
  구해 사면체로 Σ V_p K_p 를 모은 뒤 B_Tᵀ(·)B_T -- 같은 식의 재배열이라 근사가 없다 (위 5.25e-6 은 float32 잡음).
- 관성 항: 매핑이 항등인 입자는 w m/h² λλᵀ⊗I 를 사면체로 모은 일관 질량 그대로 (정확).
- 바닥 항 (softplus·stick 매핑): **매핑이 정확히 항등인 경계 s/ε > 20** (torch softplus threshold 와 같은 분기) 밖의 입자만 "바닥 후보" 로 따로 계산 --
  근사 아님. 단 lego 는 바닥 후보가 t=0 58,479 (19 %), t=40 147,088 (47 %) 로 많다 (ε=0.01 에서 s ≤ 0.2).
- 시간 (A6000 단독): 기존 헤시안 1.5 s → 입자 12x12 작은 함수 1.56 s (그대로 -- 비용은 파이프라인이 아니라 극분해 Newton 10 회의 이중 역전파),
  사면체 축약 1.03 s, + manual K 커널 0.73 s, **+ 바닥 후보 연쇄법칙 (J'ᵀKJ' + ⟨P, ∂²J_f⟩, 매핑만 든 작은 그래프) 0.47 s** -- 모두 기존 대비 5.25e-6 (같은 값).
  eigh 투영 74 ms. E 3.8 ms, E+기울기 32 ms.
  연쇄법칙 판 구간 (AF_FEM_PROF, f32): 관성 1.0 ms, **K (매핑 항등 166,662 입자, manual 커널) 17.7 ms**, 사면체 합·B 7.4 ms,
  **바닥 후보 147,088 입자 451 ms** (J' 역전파 9 회 + φ 이중 역전파 12 회 + 1 차 기울기) -- 남은 헤시안 비용은 거의 전부 바닥 후보다.
  (torch.compile 은 vmap(jacfwd) 안 matmul 에서 dynamo 오류라 manual K 는 컴파일 없이 돈다 -- 그래도 17.7 ms.)
  바닥 후보를 vmap(jacfwd) 전진 미분으로 바꾸면 오히려 744 ms (1d336d4, 기각).
  **바닥 후보 닫힌 식 (c5c1dc3, AF_FEM_FAST_NEAR=analytic)**: 매핑이 법선 좌표 s 의 스칼라 함수(w, sg, sp)와 u·G 의 다항식이라 y=(u, vec G) 공간 12x12 를
  손으로 쓴 식 (관성 R_uᵀR_u + r·∂²r, ⟨P_A, ∂²J_f⟩, J'ᵀKJ') 으로 -- 기존 대비 **5.253e-6 (같은 값)**, 헤시안 전체 **178 ms** (바닥 후보 153 ms).
  (검산 로그 dump40/fastcheck6_t0040.log 는 이 닫힌 식 판 검산으로 덮어써졌다; 전진 미분 판 수치는 fastcheck6_t0040.json 에 남아 있다.)

## F. 사면체 적분점 모델 (AF_FEM_TETQ=1, 사용자 10-27 확정 지시, 9cd316a~)

사용자 지시: MPM 처럼 고정 사면체 격자가 grid, 격자 안 계산을 FEM 이. 매 스텝 (1) P2G: 입자 질량·운동량을 노드로 (barycentric, 일관 질량), 사면체마다
안 입자들의 F_p 부피 가중 평균 F̄_T 하나, (2) 사면체마다 적분점 하나 에너지 Σ_T V_T ψ(A_T F̄_T) (V_T = 그 사면체 입자 부피 합, A_T = I + ∇u, 같은 고정 FCR ψ)
의 뉴턴 (관성·바닥·PCG·|λ| 투영·선탐색은 빠른 경로 그대로), (3) G2P: 기존 그대로 (위치·속도 barycentric 보간, F_p ← J_f F_p 입자별 누적).
**에너지가 바뀌는 새 모델** -- 기존 경로는 그대로 두고 선택지 `AF_FEM_TETQ=1` (AF_FEM_FAST=tet 와 함께) 로 추가.

구현 (lib/anchorflow/fem_fast.py `FemFrame.tetq_*`, train_deform `_newton_target_asm`):
- **바닥 항 정의를 바꾸지 않으려고** 바닥 매핑(stick·softplus)이 걸린 입자 (s/ε ≤ 20, "바닥 후보") 는 지금 빠른 경로와 **똑같이 입자 단위** (관성·탄성 모두,
  닫힌 식 12x12) 로 남겼다. 바닥 매핑은 입자마다 J_f 를 바꾸는 정의라 사면체 적분점으로 묶으면 바닥 항 정의가 바뀐다 -- 묶으려면 허락이 필요하다.
  매핑이 항등인 입자만 사면체로 모은다: 관성 = Σ_T [½ Σ_ij M_T,ij U_i·U_j − Σ_i b_T,i·U_i] + C (정확, float64), 탄성 = Σ_T V_T ψ(A_T F̄_T).
- 분할(바닥 후보/항등)은 뉴턴 걸음 시작 U 에서 정해 그 걸음 동안 고정 (에너지가 걸음 안에서 잘 정의되게). 수렴판에서는 걸음마다 새로 정하고 그 걸음 E 로 다시 잰다.
  분할 위반 (항등으로 묶었는데 받아들인 걸음 끝에 바닥 후보가 된 입자): 80 프레임 평균 0.03 개, 최대 1 개 (31 만 개 중).
- 헤시안: 활성 사면체 M_T⊗I + B_Tᵀ K_T B_T, K_T = V_T ∂²ψ(A_T F̄_T)/∂A² 를 manual 커널로 **사면체 수 (2.5 만) 만큼만**.
- 검산 (exe/fem_tetq_check.py, 덤프 t=40, float64): 조립 H·v vs 자동미분 헤시안-벡터 곱 **3.0e-16**, 기울기 vs 중심 차분 1e-7~1e-9, vs hess_mode 자동미분 4.9e-15.
  t=0 은 모든 F=I 라 F̄=I -- 기존 E 와 상대차 8e-8 (같은 값).

### H.1 바닥 항 노드 단위 (계획 (1), `--floor node`, 사용자 승인 정의 변경)
노드 비관통 장벽 Σ κ m_n/h² b(d_n; d̂) (기존 bc 장벽 b 그대로, κ 1, d̂ = 0.5·grid_lim/n_grid = 0.01) + 선택 노드 고착 Σ k_st m_n/(2h²) w_n |(I−nnᵀ)U_n|².
**노드 자기 높이로는 쓸 수 없다**: 격자가 세계 고정이라 바닥 근처 입자를 담은 사면체의 아래 꼭짓점은 처음부터 바닥 아래에 있다. 그래서
d_n = c_n + n·U_n, c_n = 그 노드가 받치는 (그 노드를 꼭짓점으로 갖는 사면체의) 가장 낮은 입자의 스텝 시작 높이 -- 입자 법선 변위 = Σλ_i n·U_i ≥ −Σλ_i c_i ≥ −s_p
이므로 모든 d_n > 0 이면 어떤 입자도 바닥 아래로 못 간다 (볼록 결합). 고착 무게 w_n = 1 − σ(c_n/ε_st) (스텝 시작 값 고정, 지연 마찰).
검산 (exe/fem_rt_check.py, 정답 t=0·40 상태, float64): 기울기 vs 중심 차분 1.6e-6 / 1.7e-10, vs 자동미분 9e-15, 조립 H·v vs 자동미분 2.5e-16.

1. **고착 (마찰) 세기가 거의 전부를 정한다**: k_st 0 이면 40 % (미끄러져 나감), 1 -> 18.1, 3 -> 15.5, **10 -> 14.2~14.8**, 30 -> 16.0, 100 -> 16.6, 1000 -> 16.4~16.8 %.
   입자 바닥의 stick 매핑은 입자마다 스텝 **끝** 높이로 w = σ(s/ε) 를 정하는 (암시적) 부분 고착이라 정지 높이 (~ε) 에서 w ≈ 0.6~0.7 의 부분 미끄러짐이 남는데,
   노드 고착은 스텝 **시작** 의 여유 c_n 으로 정해 (지연) 강하면 넘어지는 회전까지 붙잡고 약하면 미끄러진다 -- 영상에서 "정답보다 많이 넘어짐" 이 이 차이다.

**b2 계열 관통 발산 원인**: c_n = min_p s_p/λ_pn (노드 하나만 움직일 때의 한계) 은 보수적이지 않다 -- 같은 입자의 네 꼭짓점이 함께 내려가면 각자 한계 안에서도
입자는 최대 4 s_p 까지 뚫고, 뚫린 입자의 다음 프레임 c_n 이 음수가 되면 장벽이 quad 연장 영역 (d < 1e-3·d̂) 에서 유한한 힘만 내 탄성·관성에 밀려 연쇄적으로 무너졌다

- `tet_eg`: 사면체 관성 + F = A F̄, σ (닫힌 식 3x3 고유값), ψ, dψ/dF = 2μ(F−Q)+λ(J−1)sgn cof (극분해 뉴턴 10 회), 노드로 원자 합 (f64).
- `tet_hess` (스레드당 사면체) / **`tet_hess_w` (워프당 사면체, 공유 메모리 원형 순서 병렬 야코비 6 쌍 x 11 라운드)**: K = V ∂(P F̄ᵀ)/∂A (전진 미분 극분해 10 회 -- fem_fast._k_manual 과 같은 식),
  12x12 = M4⊗I + BᵀKB + 바닥 후보 버퍼, 대칭화, 12x12 야코비 고유분해, |λ| 투영 (바닥 1e-6·max), 블록 ELL 칸 (노드 x 15 칸, 노드 연속 SoA) 으로 원자 합.
- **`near_eg` / `near_hess` (`near_hess32`)**: 입자 바닥 후보 (stick -> softplus 매핑, s/ε ≤ 20) 입자당 스레드, fem_fast._near_core 닫힌 식 12x12 를 레지스터에서
  (y = (u, vec G) 공간 J'ᵀKJ' + 관성 RᵤᵀRᵤ + r·∂²r + ⟨P_A, ∂²J_f⟩, L 로 국소 12 로), 사면체 버퍼에 원자 합 -> 사면체 커널이 더한 뒤 투영 (기존과 같은 순서).
- `locate_k` / `tet_geo` / `g2p_part`: 셀 찾기·barycentric·노드/사면체 점유 표시 (cumsum 압축은 torch), 사면체 ∇λ 닫힌 식 역행렬, G2P (매핑 포함 위치·F_p <- J_f F_p).
- PCG: 블록 ELL 곱 + 블록 야코비 + 내적 융합. `pcg2_*` (2 커널/반복, 스칼라 판정 GPU, 반복 10 회 묶음 CUDA 그래프, 버퍼 최대 크기로 미리 잡아 프레임 넘어 그래프 재사용),
  **`pcg_coop1` (지속 커널 -- 반복 전체가 커널 한 번, 블록 사이 소프트웨어 장벽 2 회/반복, 호스트 동기화 없음; 블록 수는 상주 한도로 계산 -- 넘기면 교착 (실측))**.

### H.6 Vertex Block Descent (사용자 10-28 추가 지시, `--solver vbd`)
같은 증분 포텐셜 (관성 + 사면체 적분점 탄성 + 입자 바닥 softplus·stick) 을 노드 3x3 블록 가우스-자이델로: Kuhn 격자 노드 8 색 (색 = (g₀ + 2g₁ + 4g₂) mod 8 -- 0/1 오프셋 이웃끼리,
따라서 한 사면체의 네 꼭짓점·한 입자의 네 노드가 모두 다른 색), 색마다 `vbd_tet_g` (사면체 -> 그 색 꼭짓점의 국소 기울기) · `vbd_near_g` (바닥 후보 입자 -> 그 색 노드, _near_core 의
기울기 식) · `vbd_node` (U_n -= H_n⁻¹ g_n) 커널. H_n = 걸음 시작의 투영 사면체 헤시안 (워프 커널) 을 모은 노드 대각 블록 (|λ| 투영된 양정치), `--vbd_refresh 1` 이면 매 반복 지금 상태에서 다시.
검산: 8 색 국소 기울기 합 (float32) vs 전체 기울기 (float64) 상대차 1.1e-5.
선탐색 없는 원래 VBD 는 접촉이 시작되는 프레임 7~10 에서 비유한 (det -> 0) 으로 발산했다 (v_n5~n40, 모두) -> 노드 한 번 이동 상한 0.1·node_h 와 비유한 걸음 무시를 넣었다.

### I.1 혼합 정밀도 반복 개선 PCG (`--pcg2 4`, 커널 pcg_mix)
지속 커널 하나 안에서 탐색·잔차·해 벡터·블록 야코비·곱을 모두 float32 로 돌리고, 재귀 잔차가 지난 갱신 뒤 최대의 δ 배 아래로 내려가면 (그리고 멈추기 전에는 반드시)
x_hi (float64) += x_lo, r = b − A x_hi 를 float64 누적으로 다시 재는 신뢰 갱신 (reliable update, 탐색 방향은 유지). **멈춤 판정은 float64 실제 잔차 < rtol 1e-6 로만** 한다.

PCG 단독 검산 (exe/fem_rt_mix_bench.py, 정답 상태, 최종 판과 같은 대칭 반쪽 행렬):

### K.6 정리
- 남은 시간의 2/3 는 PCG (~600 회 x 26 µs). 반복을 줄이는 전처리는 모두 전역 장벽 수 (SSOR) 나 성긴 차원 (deflation) 때문에 이 크기 (노드 1.7 만) 에서 시간 이득이 없고, 접촉 deflation 은 가정 자체가 틀렸다 (낮은 모드가 접촉에 없음).

### L.0 모델 (암시적 최종 판과 같은 것 / 다른 것)
같다: 사면체 적분점 (셀별 F̄_T = 매핑 항등 입자의 부피 가중 평균, P2G), 고정 FCR (같은 ψ·P 식, σ 하한 0.01), 중력, 감쇠 (ficus --pg_vdamp: 서브스텝마다
0.9999^(h_s/substep_dt) -- 프레임 합이 같다), --cfg_bc (묶인 노드 속도 = v_bc), 입자 바닥 (stick -> softplus 매핑, 바닥 후보 = 프레임 관성 예측 끝 높이 s/ε ≤ 20,
노드 바닥 안 씀).
명시적 서브스텝 (h_s = h/N): f = −∂Ψ_far/∂x − ∂E_fl/∂x (지금 상태), v ← (v + h_s (f/m + g)), x_n += h_s v.
- **바닥 항**: 기존 입자 바닥 에너지를 프레임 단위 그대로 (걸음 h, 프레임 시작 x0·F0, c = h v + h² g)
  E_fl(u, G) = m/(2h²)(|q(x0+u) − x0 − c|² − |u − c|²) + V ψ(J_f F0)  (첫 항 = 매핑이 바꾼 관성 몫, 둘째 = 바닥 후보 입자 탄성 (사면체 F̄ 에서 빠짐)),
  그 음의 기울기를 매 서브스텝 힘으로, 매핑 자체는 프레임 끝 G2P 에 한 번 (암시적 판 G2P 와 같은 식).
  **서브스텝마다 매핑을 쓰면 안 된다**: softplus 이동 sp(s) − s 는 걸음 길이와 무관하게 한 번 쓸 때마다 같은 양 (s = ε 에서 0.0031) 을 옮겨,
  N 번 쓰면 N 배로 밀어 낸다 (진단 diag_lag_n64·n1024: 첫 서브스텝 노드 |v| 160 m/s·783 m/s, 바닥 없이는 1.3 m/s). 그래서 위처럼 프레임 단위 에너지의 힘으로 바꿨다.
- sub (MPM 식): 매 서브스텝 P2G (질량·속도·F̄) -> 힘 -> 선형 G2P (x += Σλ ΔU, F ← (I + Σ ΔU ⊗ ∇λ) F, v = ΔU/h_s).
- lag (라그랑주): 프레임 동안 격자 노드가 움직인다 (U 누적, 셀 F = A_T(U) F̄_T), 바닥 후보는 u = Σλ U 보간, 프레임 끝 선형 G2P (v = Σλ v_n).

### L.1 CFL 과 노드 질량 (지시대로의 모델 = 노드 질량 Σ λ m_p 가 발산하는 원인)
CFL (파속·노드 간격): lego c = √((λ+2μ)/ρ) = 36.7 m/s, Kuhn 사면체 최소 높이 0.01414 (= node_h/2) -> Δt_CFL 3.85e-4 s -> **N_CFL = 43**.
ficus c = 247 m/s (ρ 70), 최소 높이 0.0283 -> Δt_CFL 1.14e-4 s (h = 0.04) -> **N_CFL = 350**.
그러나 노드 질량 Σ λ m_p (암시적 판 관성 행렬 Σ_p m_p λλᵀ 의 행 합) 는 꼭짓점 쪽 입자가 거의 없는 노드에서 꽉 찬 노드 질량의 2e-6 까지 작아지고
(선형 barycentric 은 λ → 0 이어도 ∇λ 가 0 이 아니라 그 노드가 받는 탄성력은 그대로), 노드 국소 안정 걸음 2/ω (ω² = Σ_T V_T(λ+2μ)|∇λ_i|²/m_i) 은
첫 프레임 최소 1.3e-5 s (**N ≥ 1287**), 1e-3 분위 2.5e-5 s 다 (진단 diag·d2). λ 는 0 에 얼마든지 가까워질 수 있어 프레임마다 더 작은 질량이 나온다:

| 판 (노드 질량 Σλm, 바닥 있음) | N | 결과 |
|---|---|---|
| lag | 64 / 1024 / 2048 / 3072 / 4096 / 6144 / 8192 | 발산 프레임 1 / 1 / 2 / 7 / 9 / 25 / 26 (8192 은 980 ms/프레임) |
| sub | 1024 / 2048 / 4096 / 8192 | 발산 프레임 2 / 1 / 13 / 42 (8192 은 8.0 s/프레임) |
| lag 바닥 없음 (20 프레임) | 1024 / 2048 / 4096 | 발산 1 / 2 / 완주 (136 ms/프레임) |
| ficus lag / sub (바닥 없음) | 1024·4096·16384 / 1024·4096 | 모두 발산 (프레임 1~3) |
-> **지시대로의 질량으로는 시험한 어떤 N (lego ≤ 8192, ficus ≤ 16384) 에서도 끝까지 못 간다.** 이것이 지시 모델의 측정 결과다.

**정의 변경 판 (참고, `--mass tet`)**: 노드 질량을 사면체 등분 Σ_T m_T/4 (m_T = 그 사면체 입자 질량 합; 선형 사면체 표준 질량 집중 -- 질량·운동량 합은 같다) 으로 바꾸면
질량 대 강성 비가 사면체 모양으로 묶여 CFL 근처에서 안정해진다. 아래 L.2~ 의 완주 판은 모두 이 정의 변경 판이다 (관성 정의가 다르므로 사용자 확인 필요).

### L.6 정리
- **지시대로의 명시적 모델 (노드 질량 Σλm) 은 lego·ficus 모두 시험한 모든 N (lego ≤ 8192, ficus ≤ 16384) 에서 발산한다** -- λ → 0 인 노드의 질량이 0 에 가까워 국소 안정 걸음이 파속 CFL 보다

### M.0 모델
- 격자 = 기존 노드 격자 (simplex.lattice(node_h, HZ_CUBE·node_h) = 몸대각선 z 의 정육면체 격자, 간격 dx = node_h/√2: lego 0.02, ficus 0.04 -- 기존 `--interp bspline2`·simplex.bspline27 과 같은 가중치),

- 한 서브스텝 h_s = h/N (PG p2g2p 순서): **P2G** m_n = Σ w m_p (질량 정의 그대로), (mv)_n = Σ w m_p v_p + h_s f_n,  f_n = −Σ_q V_q τ_q ∇w_n(x_q) (τ = P(F)Fᵀ, 고정 FCR -- 사면체 판과 같은 ψ·P, σ 하한 0.01)

- 적분점 둘: **입자** (MPM 식, τ_p = τ(F_p), ∇w 는 입자 위치 -- ∇w 가 w 와 함께 0 으로) / **셀 대표** (base 가 같은 입자 = 같은 27 노드 지지 = 셀, F̄_c = Σ V_p F_p / Σ V_p, V_c = Σ V_p,
  ∇w 는 셀 안 K 점 평균 ḡ -- K 1: 중심, K 8: 2x2x2 가우스점).
- 바닥 (lego): 절 L 과 같은 입자 바닥 (softplus·stick, 프레임 시작 분할 = 관성 예측 Σw(h v_n + h² g) 끝 높이 s/ε ≤ 20, 프레임 단위 바닥 에너지의 음의 기울기를 서브스텝 힘으로 -- (w, ∇w) 로 노드에,
  매핑은 프레임 끝 한 번 ex_near_fin). 바닥 후보 입자는 탄성 적분점에서 빠진다. 노드 바닥 안 씀.

### M.6 정리
- **2 차 B-스플라인 + 입자 적분점 (MPM 식) 으로 질량 정의 Σwm 을 바꾸지 않고 안정한 명시적 판이 된다**: lego N ≥ 88 (h_s ≈ 0.35 Δt_CFL, 바닥 없으면 N ≥ 48), ficus N ≥ 448 (0.55 Δt_CFL).
  ∇w 가 w 와 함께 0 으로 가 국소 안정 걸음이 노드끼리 고르다 (lego 9.5e-4~1.2e-3 s). 절 L 의 Σλm 사면체 판 (모든 N 발산) 과 대비된다.
- **셀 대표 적분점 (F̄, K 1·8) 은 어떤 N 에서도 첫 프레임 발산** (lego ≤ 4096, ficus ≤ 16384): ḡ 가 w 와 함께 0 으로 가지 않아 질량 1e-20 노드에 유한한 힘 -- 국소 필요 N 10⁶~10⁷. 절 L.1 과 같은 병리.
- 오차: lego 12.375 % (사면체 등분 12.21 %, 암시적 11.19 %), ficus **1.453 %** (가장 작다). ficus ψ 띠 밖 정체는 없어졌지만 PIC 감쇠로 진동이 거의 없다 (정답은 APIC).
