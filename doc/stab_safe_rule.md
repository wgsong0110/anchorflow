# 서브스텝 안정성: 발산 방지 보정판 규칙 (2026-10-12, 사용자 지시)

목적: 작은 N 에서 발산해 죽는 설정도 끝까지 돌려 지표를 재기 위한 **공통** 안전장치. 그래프에서는 보정판 점을 다르게
표시한다 (빈 마름모, 개입 수 함께). **네 방법(PG·GF·i-PG·우리) 모두 같은 규칙.** 구현: lib/anchorflow/stabstat.py
(safe_params, safe_fix, clamp_F), exe/stab_mpm.py --safe 1 (PG·i-PG), exe/gf_mpm.py --safe 1 (GF).

## 규칙 (서브스텝마다)
- 서브스텝 전: 이번 스텝에 영역 상자 [3dx, GL−3dx] 밖으로 나갈 입자의 속도만 상자 안에 멈추게 자른다
- 서브스텝 후:
  1. 위치·속도·F(·F_trial·C) 중 비유한이 생긴 입자는 입자 상태 전부를 직전 값으로, 속도 0
  2. 속력 상한 VCAP = 10·sqrt(2 g H) (H = 처음 최고점의 바닥 위 높이, 자유낙하 최고 속력의 10 배) 로 자른다
  3. 위치를 영역 상자 안으로 자른다
  4. F 의 특이값이 10 을 넘으면 10 으로 자른다 (아래 한계는 없음 -- 아래 참조)
- 솔버가 예외로 죽으면(i-PG GMRES 안 SVD 미수렴 등): 직전 상태로 되돌리고 같은 시간을 반씩 둘로 나눠 다시 푼다 (깊이 6,
  1/64 까지). 끝내 실패하면 그 스텝은 관성만으로 전진 (v += h g, x += h v, 상자 안으로)
- 개입 수를 프레임마다 기록: safe_n (클램프·되돌림 입자 수 누적), safe_split (반으로 나눈 횟수), safe_inert (관성 대체 횟수)

## 정상 실행에 영향이 없는가
- 조건이 전부 "발산 조짐" 에서만 참이 되도록 잡았다. 확인: 보정판으로 PG N64 (lego 20 프레임), GF N16 (lego 60 프레임)
  을 돌려 개입 0 건, 위치 차이는 보정 없이 두 번 돌린 차이(원자적 덧셈 비결정성: PG 1.6e-6, GF 1.5e-3)와 같은 크기
- 우리 방법은 지금까지 끝난 실행 전부 비유한·상자 밖·속력 상한 초과가 없어 같은 규칙이 개입하지 않는다 (다시 돌리지 않음)
- F 아래 한계를 두지 않는 이유: 발산하지 않은 정상 실행에도 det F ≤ 0 인 뒤집힌 입자가 있다 (우리 lego N1~8 det 최소
  −1.07, GF ficus N16 −2.79, i-PG N8 −2.33, GF mic 정상 실행 det 최소 0.06). 아래를 자르면 정상 실행을 바꾼다
