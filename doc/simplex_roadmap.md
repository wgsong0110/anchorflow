# 사면체 복합체 전환 로드맵

작성 2026-09-29. 사용자가 이 시점부터 관여하지 않기로 했으므로, 이 문서를
기준으로 끝까지 진행한다. 상태는 진행하면서 이 파일에 갱신한다.

되돌아올 지점: 태그 `grid-rqs-final` (격자+RQS 시대의 마지막 상태).

## 0. 목표

격자 위 conv + 격자점 dp 출력을 **사면체 복합체 위 GNN** 으로 갈아탄다.
사면체가 셀이고, 점유 사면체의 꼭짓점만 노드다. 접힘 방지는 dp 크기 제한이
아니라 **det 제약**(무효 사면체는 탄성에서 빼고 복구 손실로 되돌림) 으로 한다.

## 1. 확정된 설계 (바꾸지 말 것)

- **기하**: 발판 셀 -> 소큐브 8 -> Kuhn 6 = 셀당 48 사면체. 48 대칭 불변.
- **노드**: 27 종 좌표 전부(코너·변중점·면중심·몸중심) 독립 자유도.
  2 배 격자 정수점으로 색인. 코너 평균 유도 없음.
- **점유만**: 입자가 든 사면체의 꼭짓점만 노드, 그 사면체의 변만 간선.
- **간선**: 방향까지 구분한 26 종 (`{-1,0,1}^3` 의 0 아닌 오프셋).
- **전달**: 사면체 4 꼭짓점 barycentric. 이것 하나뿐 (trilinear·B-스플라인·
  skin 은 전부 삭제됨).
- **셀 내부 변형**: 항등 (RQS 는 복합체 전환으로 의미를 잃어 삭제한다).
- **접힘 방지**: `det(grad Phi) < --det_eps(0.1)` 인 사면체는 **탄성항에서만**
  제외(관성·중력·접촉 유지) + `--det_w(100)` 배 복구 손실
  `softplus(-(d-eps)/tau)*tau + 10*relu(-d)^2`.
  **dp 크기 상한(BoundedWarp)은 쓰지 않는다. 지시 없이 절대 켜지 말 것.**
- **인자**: 사용자가 만지는 해상도는 `--n_nodes`(노드 간격) 하나.
- **속도**: `v = dPhi/dt` (torch.func.jvp). 차분 금지.
- **F**: `F <- grad_x Phi * F`, 해석적 닫힌 형식.
- **목적함수**: 입자에서 바로 재는 증분 포텐셜 (`--obj pts`). MPM 격자 미사용.

- 긴 작업은 백그라운드(tmux + `run_in_background`)로 띄우고 바로 다음 일로

## 8. 2026-09-30 구조 전면 개편

사용자 지시로 설계가 바뀌었다. 이전 절의 수치(롤아웃 0.62~0.73)는 **모두 옛
구조·옛 교사 기준**이라 새 구조와 비교할 수 없다.

### 8.1 격자: 몸대각선을 z 로 세운 고정 Kuhn

옥탄트마다 대각선을 꼬아 48 겹 큐브 대칭에 불변으로 만들던 것을 버리고, **모든
셀이 같은 몸대각선 (1,1,1)** 을 쓰도록 고정하고 그 방향을 z 에 세웠다. 일부러
방향 의존적인 구조다.

- 격자 기저 `a_i = (r*u_i, hz)`, `r = h/sqrt(3)`, `u_i` 는 120 도 간격.
  `|a_i-a_j| = h` (면내 최근접), `sum a_i = (0,0,3*hz)` (몸대각선).
  `hz = h/sqrt(6)` 이면 정육면체다.
- 그 방향에서 보면 층이 xy 평행 **정삼각 격자**이고 **ABCABC** 로 쌓인다.
  1 층과 4 층의 같은 사영 위치를 잇는 것이 몸대각선(3 층 간격)이다.
- 면내 h 와 층 hz 를 따로 주므로 쌓기끼리의 차이가 그 두 값에만 들어간다.
- **간선 26 -> 14 종**: 격자축 6(1 층) + 면대각 6(2 층) + 몸대각 2(3 층).
  `(1,-1,0)` 류는 이 분할에 없어 **같은 층 안에는 변이 없다**.
- 노드는 격자 정수점 **한 종류**다 (2 배 격자 27 종은 소큐브 분할 때문이었다).
- 단위검사 19/19 (`exe/test_simplex.py`): 기저·쌓기·아핀 재현 5.7e-16·C0·
  해석 야코비안 == autograd 오차 0·간선 14 종 양방향·층 내 변 0 개.

### 8.2 로컬(셀 내부) 변환 전부 삭제

지시대로 셀 내부는 **항등만** 남겼다. 지운 것: `tet_n_params`/`_mono_rqs`/
`tet_remap`, `SimplexGNN` 의 rqs 출력 경로, `--cell_warp`/`--rqs_bins`,
`conv_stepper` 의 rqs 헤드, `test_tet_remap.py`. 복구 태그도 지웠다.
부수 효과로 변형장이 사면체별 아핀이 되어 야코비안이 닫힌 형식 하나가 된다
(재배열 시절 필요했던 역전파 3 회가 사라진다). 실측으로도 재배열이 전체 입자
순전파 29.8ms 중 21.5ms 를 먹던 병목이었다.

### 8.3 하드 구속 (손잡이 + 바닥)

교사도 i-PG 방식(Δu 하드 고정)으로 바꾸므로 학생도 맞췄다.

- `ctrl_weights` 기본이 지시함수(반경 안 1, 밖 0)다. `--ctrl_soft` 로 옛
  감쇠 가중 `(1-q^2)^2` 복원.
- `phys_resid.bc_project` 가 바닥·경계를 하드 사영한다. 한쪽 부등식이라 활성
  집합을 매 스텝 다시 잡는다. 하드일 때 `AF_NO_BC` 로 벌점을 끈다.
- **출력 일치 항** `L_bc = mean|corr|^2/ext^2`, `corr = 사영된 출력 - 원 출력`.
  이게 없으면 망은 구속 자리에서 무엇을 내든 덮어쓰기가 대신 처리해 변형장이
  경계조건과 어긋난 채 남는다. 자유 입자는 corr 이 정확히 0 이다.
- 진단(`bc_report`): 활성 13%, **바닥아래 0.00e+00** (옛 벌점은 관통 0.97%).

### 8.4 부분표본 삭제 -- 교사와 같은 입자 집합

옛 구조는 전체 251001 -> 저장 20000(8%) -> 매 스텝 8000 의 **이중** 표본추출
이었다. 매 스텝 재추출은 하고 있었지만 모집단이 8% 로 고정이라 나머지 92% 를
영원히 못 봤다. `--n_pts` 와 모든 부분표본 구성·질량 보정·`with_ctrl` 을 지우고
항상 전체를 쓴다. 궤적 생성도 기본이 전체 저장이다.

근거: 전체 251001 입자 순전파가 집계 5.3 + GNN 1.2 + 전달 1.9 = **8.3ms
(120FPS)** 로 측정됐고, 역전파는 노드 수에 묶여 입자 수와 무관하다. 즉 속도
때문에 부분표본이 필요하다는 전제가 틀렸다 (`exe/bench_fullN.py`).

### 8.5 학습에서 교사 궤적 사용 전부 삭제, 상태 풀이 유일 경로

지운 것: 교사 프레임에서 t0 를 뽑는 배치 루프(72 줄), `phys_window`(148 줄),
`window`(146 줄, 지도 손실), `quick_val` 의 보조 지표.

학습은 씬의 **정지 상태**(x = 채운 입자, v=0, F=I)에서 출발해 손잡이 계획을
직접 뽑고, 모델이 상태를 한 스텝씩 갱신하며 그 상태에서 물리잔차만 잰다.
교사 궤적은 평가·검증의 기준으로만 읽는다. `--no_pool` 은 학습 경로가 없어
즉시 종료한다.

이유: 교사 상태로만 배우면 추론에서 학생이 만나는 자기 상태와 분포가 어긋난다.

### 8.6 교사를 i-PG 로 교체

- 손잡이를 **하드 Dirichlet 격자 BC** 로 등록한다(`exe/patch_ipg_handle.py`).
  implicit 솔버의 `bc_mask` 는 `grid_postprocess` 가 바꾼 노드에서만 잡히므로,
  기존의 입자 속도 감쇠 혼합은 Newton 반복이 그대로 풀어 버렸다.
- 해상도 두 종: `n_grid 100`(원본, dx 0.020)과 **`58`**(우리 노드 간격
  hn=0.0343 에 맞춘 것). 채움 격자는 둘 다 100 으로 고정해 입자 집합을 맞춘다.
- `fix_pg_filling` 이 **필수**다. 없으면 `densify_grids` 의 `ti.sym_eig` 가 f32
  등방 공분산에 inf 를 뱉고 `r` 이 정수로 넘쳐 채우기가 끝나지 않는다
  (GPU 100%, 로그 무음으로 2.5 시간 매달렸다).
- `--dt_multiplier 8`. implicit 을 explicit dt(5e-5)로 돌면 16 시간이다.

### 8.7 속도 최적화 (풀 학습 1.42 -> 0.61 초/스텝, 2.3 배)

`AF_PROF=1` 구간 계측으로 짚었다. 전체 입자(251001), 배치 8, A6000.

| 구간 | 전 | 후 | 조치 |
|---|---|---|---|
| 소성·풀 | 525ms (26%) | 17ms (1%) | 고유분해 공유 + 항복 입자만 |
| 에너지 | 372ms | 135ms | 고유분해 f32 (3.2 배) |
| 셀집계 | 189ms | 101ms | `edges_of` 에서 사면체 먼저 중복 제거 |
| 야코비안 | 17ms | 4ms | `locate` 재호출 제거 |
| 신경망 | 82ms | 121ms | (jvp 안에 들어가며 계측 위치가 바뀜) |

- **소성**: `psi_of` 가 `(psi, Plast(dlog, V))` 를 돌려주고 `plastic_step` 이 그
  기저를 받아 쓴다(재분해 없음). `dlog` 가 정확히 0 인 입자는 건너뛴다 --
  `P = V diag(exp(0)) V^T = V V^T = I` 라 수학적으로 항등이고, `_vm_project` 가
  비항복 입자에서 `over`/`dg` 를 정확히 0 으로 두므로 `eps2-eps` 가 비트 단위
  0 이다. 건너뛰면 float64 직교성 오차조차 없어 **더 정확하다**.
  검증 7/7 (`exe/test_plastic_equiv.py`): 비항복 입자 F 가 비트 단위 동일,
  항복 입자 최대차 9.5e-07 (fp32 반올림), 중앙 오차 0.
- **f32 고유분해**: 실측 f64 43ms -> f32 14ms, 비유한 0 개. 탄성에너지 합
  상대오차 ~1e-07, 기울기 2.4e-04. 교사 궤적이 fp16(해상도 ~1e-3)로 저장되므로
  F 의 2.4e-05 오차는 데이터 정밀도보다 훨씬 아래다. `AF_SIG_F64=1` 로 되돌림.
- **`edges_of`**: `idx_rows` 가 입자마다 한 행이라 251001 입자면 변 쌍이 300 만
  인데 서로 다른 사면체는 수만 개뿐이다. 먼저 줄여도 변 집합은 같다.
- **`locate` 재호출 제거**: `_fieldS` 안의 `g2p` 가 `locate` 를 다시 돌았다.
  `locate` 는 tau 에 무관한데 jvp 안이라 정방향 미분까지 두 번 탔다.
  `g2p_pre`/`g2p_jac_pre` 로 미리 구한 `(rows, lam, aux)` 를 재사용한다.
- **손잡이 가중치**: tau 에 무관한데 `_fieldS` 안에서 **두 번** 호출됐다.
  스텝당 한 번만 구하고 tau 의존분(명령 변위)만 안에서 만든다.
- **GPU 동기화**: 에너지 반환의 `float()` 4 개 x 배치 8, 풀 루프의
  res/isfinite/loss/영역이탈 3~4 개 x 배치 8 이 매 스텝 파이프라인을 세웠다.
  보고항은 텐서로, 풀 루프 스칼라는 `stack(...).tolist()` 로 한 번에 내린다.

고친 결함 셋: 드라이버가 `$NG` 를 tmux 셸에 넘기지 못해 두 해상도가 같은 출력
경로를 써서 충돌한 것, 풀 루프가 전역 `N_FULL` 을 씬 입자 수로 덮어써 교사 기반
평가가 범위 밖을 읽어 device-side assert 가 난 것, `load_scenes` 가 `n_pts=0`
을 빈 집합으로 해석한 것.
