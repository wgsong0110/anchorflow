# 서브스텝 안정성 실험 (2026-10-09 지시)

주장: "우리 표현 방법은 더 적은 서브스텝으로 안정하다".

- 방법: PG(공식 명시 MPM, APIC) · i-PG(암시 MPM, newton_gmres) · GaussianFluent(gf_mpm 이식본, FLIP 0.7) · 우리(rep_ip: 사면체 격자+스키닝 표현 위 증분 포텐셜 최소화)
- 재질: 탄성만 (fixed corotated jelly), E 1e6, ν 0.3, 밀도 1000 (i-PG visco_drop 씬의 값, 소성만 뺌)
- 장면: lego · mic · ficus, i-PG visco_drop 0 프레임 입자(PG 공식 채우기) 그대로, 정지 낙하, 바닥 z 0.48, g -9.8, 격자 100 (dx 0.02), 1/60 s × 60 프레임
- 서브스텝 N (프레임당): dt = frame_dt / N. 명시 방법은 CFL(0.6 dx/음속) 배수도 함께 표기
- 기준 궤적: 방법마다 N 을 두 배씩 올려 N 과 2N 의 부분표본 RMSE/L < 0.5% 가 되는 2N. 같은 설정 두 번으로 재현성 바닥을 먼저 잰다
- 안정 판정(고정, lib/anchorflow/stabstat.py): NaN · 상자 밖 0.1% · 운동+위치 에너지 > 1.5×처음 · det F ≤ 0 > 1% · 최대 속력 > 10×자유낙하 상한
- 오차: 기준 궤적 대비 부분표본(32768, 같은 번호) RMSE/L 프레임별·평균
- 산출: N_min 표, N-오차 곡선, 시간-오차 그림, 같은 N 대표 영상. 속도는 마지막에 단독 GPU
- 우리 방법의 서브스텝 최적화 반복은 고정 (iters0/iters), 반복 수를 보고에 남긴다
