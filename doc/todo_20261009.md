- 산출: (a)(b) 각각 MPMAvatar | PG 나란히 영상
- [x] 3DGS 재학습 (바른 방향, PSNR 33.5) -> [x] 시뮬·렌더 (exe/flag_sim.py)
- [x] PG 찢김 해결: 깃대 띠 격자 속도 고정(PG 공식 cuboid) + 격자 125 (칸 2 cm). 격자 250 이면 입자 한 겹이라 끊어진다
