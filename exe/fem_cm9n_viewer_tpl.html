정의: 우리 틀은 프레임당 P2G 한 번 → 메시 (노드) 위 K 걸음 풀이 → G2P 한 번이라 입자 위치는 프레임 끝에서만 바뀐다. 그래서 입자마다 그 입자가 속한 칸 (프레임 시작 위치 기준 B-스플라인 칸: 노드 27 개, 가우스 점 8 개) 의 상태로 판정한다.
NaN 시점 = 칸의 27 노드 변위 (y 또는 U) 또는 8 가우스 점 상태 (F_q, S_q) 가 처음 비유한이 된 걸음·뉴턴 반복 (그 안 단계: 시작점 → 뉴턴 i 기울기 → 뉴턴 i 끝 → 걸음 끝 → 커밋). 칸 상태가 끝까지 유한하면 'G2P 에서 처음'.
원인 = 칸에서 가장 먼저 생긴 것: (a) 노드 변위 비유한, (b) 가우스 점 시험 X = F_q + ∇U F_q 의 J ≤ 0 (유한), (c) 응력 (같은 식으로 다시 계산) 또는 노드 기울기 비유한, (d) 가우스 점 상태 비유한. 같은 시점이면 a > b > c > d.
위치 = 발산 프레임 직전 프레임 끝 (= 발산 프레임 시작) 입자 위치.
